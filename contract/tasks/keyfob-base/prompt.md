Design the PCB for a two-button 433 MHz remote-control keyfob.

- It must fit inside the plastic shell of a Volkswagen Golf Mk6 flip key, in
  place of the original board.
- It runs from a single CR2032 coin cell held on the board.
- Two momentary push buttons, each of which makes the fob send a different code.
- An EV1527-compatible learning-code OOK encoder generates the codes and keys a
  433 MHz ASK transmitter.
- An LED lights while the fob is transmitting.

Choose component values from the parts' datasheets. Deliver a fab-ready board.
